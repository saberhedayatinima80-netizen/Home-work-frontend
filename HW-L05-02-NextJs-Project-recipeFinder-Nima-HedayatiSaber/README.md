# HW-L05-02-NextJs-Project-recipeFinder-Nima-HedayatiSaber

Recipe Finder web app (Next.js) with:

- Home page search
- Search results grid + filters + pagination
- Recipe detail page
- Favorites with `localStorage`
- About page

## API

Set your Spoonacular key in `.env.local`:

```bash
NEXT_PUBLIC_SPOONACULAR_API_KEY=your_key
```

If no key is set, the app falls back to a free demo API so it still works.

## Run

```bash
npm install
npm run dev
```

## Build static site

```bash
npm run build
```
