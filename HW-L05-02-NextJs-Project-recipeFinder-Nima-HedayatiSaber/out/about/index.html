About

Recipe Finder helps you discover meals by ingredients, cuisine, or keywords.

HW-L05-02-NextJs-Project-recipeFinder-Nima-HedayatiSaber

This app searches recipes, shows details (ingredients + steps), and lets you save favorites in localStorage. It uses Spoonacular when an API key is set, otherwise a free demo data source so the project still runs.

  • Home search experience
  • Grid results with filters and pagination
  • Recipe detail page
  • Favorites with add/remove
