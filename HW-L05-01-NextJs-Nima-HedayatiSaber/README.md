# HW-L05-01-NextJs-Nima-HedayatiSaber

Simple Next.js blog with dynamic routes.

## Features

- Home page (`/`) loads posts from JSONPlaceholder and shows the first 5
- Each post shows title + short body
- Clicking a title opens `/posts/[id]`
- Detail page shows full `title` + `body`

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build static site

```bash
npm run build
```
