# Expense Tracker (React Context)

Homework L03-03 — React Context API.

## Features
- Add income / expenses (title, amount, date, category)
- Default + custom categories
- Pie chart (expenses by category) and line chart (income vs expense over time), pure SVG
- Global state with Context API + `useReducer` (`ExpenseContext`, `AuthContext`), persisted in LocalStorage
- Sign up / sign in with LocalStorage, profile shown on the dashboard
- Search (title / amount) and filter (category, date range)
- CSV import / export
- Responsive dark UI

## Run
```bash
npm install
npm run dev
```
